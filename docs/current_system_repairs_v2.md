These refusals execute neither research tools nor a model call; forcing another family cannot bypass the boundary. The report explains the unavailable target and the supported alternative.

Causal summaries include the ATE estimand, treatment, outcome, unit, adjustment set and supplied assumptions. The text explicitly distinguishes mathematical checks from empirical verification, and preserves the synthetic-only scope.

The tool-only comparison arm retains its writer. Rankings, cutoff, horizon, candidates, numerical model and evaluation evidence are unchanged.

Workflow `wf-v2`, prompts `prompts-v11`, critic `critic-v9 structural-v1 research-v2`. Old paused investigations retain their original identities and cannot silently adopt changed workflow/prompts. Restart a running console to load the updated code, then start a new investigation.
