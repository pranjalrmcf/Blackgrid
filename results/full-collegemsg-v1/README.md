# Full CollegeMsg ingestion

Validated 59,835 events across 1,899 people and 13,838 distinct undirected connections.

Exact duplicate rows: 37; retained and flagged. Malformed rows: 0.

All records were read. Only aggregate statistics and hashes were saved. This prepares the data for future research; it does not test whether groups are unusual or establish why people communicate.

The previous seven-day experiment is unchanged. No LLM calls or paid services were used. See ingestion.json for the source, versions, counts and limitations.
