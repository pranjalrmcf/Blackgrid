# BLACKGRID — Production gap analysis

Phase 1, 22 October 2026. Evidence is static source review plus the [executed baseline](baseline_test_report.md). Priorities mean P0: blocker before remote/untrusted or multi-user exposure; P1: blocker for a reliable managed deployment; P2: measurement-led improvement. A static risk is not a reproduced exploit or measured bottleneck. Passing unit tests is not a security certification.

## Coverage by production concern

| Concern | What already exists | Remaining evidence needed |
|---|---|---|
| Reliability/recovery | Per-run fencing, durable operations, checkpoints, receipt hashes, manual uncertain-billing reconciliation, recovery regressions | Process termination, disk-full, DB interruption, coordinated restore, bounded cancellation and shutdown in deployment |
| Security | Loopback bind, Host/token checks, strict inputs, allowlisted tools, path containment, safe embedded data, provider endpoint allowlist | Multi-user policy, OS limits, ingress abuse tests, secret-redaction review, dependency/container scans |
| Scalability/performance | One console action, graph/event/candidate/training limits, deterministic caches, threadpool limit for behavioral ML | API/job throughput and latency, queue behavior, sustained concurrency, memory/CPU and resource ceilings |
| Maintainability/testing | Typed schemas, protocol/decision records, dependency lock, broad scientific and recovery tests | CI matrix, lint/type policy, API compatibility/versioning, packaged deployment checks |
| Observability/LLMOps | Run/operation identities, aggregate tool timings, tokens/costs, saved prompts and responses locally | Redacted service events, metrics, trace propagation, alerts and actual workload-based SLOs |
| Deployment/data integrity | Explicit local config and checksum gates; atomic core writes; known directory layout | Container image, lifecycle, secret mounts, health checks, consistent backups, release rollback |
| Cost management | Default mock mode, persisted reservations, authorization scope, token/call/spend ceilings | Cross-run atomic budget admission, cost dashboards/alerts, no paid-parallel execution until verified |

## Limits and decisions

No load test, penetration test, dependency scan, restoration drill, cloud deployment, paid LLM call, or analytical efficacy experiment was performed. No throughput, latency percentile, capacity, availability, security-cleanliness or production-ready claim follows from this audit.

Continue preserving scientific windows, model/prompt identities, call sequencing, held-out isolation, observed/missing-edge distinctions and evidence labels. Containerization must not silently select a different forecast model by omitting its promotion evidence. Real-data rights are not expanded by a production roadmap. Basic local instrumentation remains useful even if a full monitoring stack is deferred.
